llm-actuators

The system in a nutshell

Sterile primitives that let an LLM drive a real machine — devices, browsers, designs, processes, and other agents. Each tool does one thing through a parseable CLI; the power is how they compose into a supervised multi-agent fleet.
Hover any box to trace its integrations — teal = what it drives, coral = what drives it. Or run a scenario to watch a real task flow through the stack.
Scenario:
27 tools, one job each — composed into one supervised fleet. Three backbone hubs carry the system: switchboard (the message bus), substrate (the scaffold), and semantic-schema (the shared data contract). Hover any box to trace its integrations, or run a scenario above.
27 single-purpose repos across Rust, Swift, Go and Shell — supervised, R&D-grade, self-built. Every line is a runtime integration between tools; the arrow points from the caller to what it drives. One canonical layer model; the static architecture diagram in the org README renders the same graph.
